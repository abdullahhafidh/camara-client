# CAMARA API Structure

This document lists all CAMARA APIs organized by category as defined in [CAMARA API Overview](https://camaraproject.org/api-overview/).

## Mature APIs

### Authentication and Fraud Prevention
- **Call Forwarding Signal** - Signal call forwarding events
- **Customer Insights** - Get customer insights and analytics
- **Device Swap** - Detect and manage device swap events
- **Know Your Customer Age Verification** - Verify customer age
- **Know Your Customer Fill In** - Fill in KYC information
- **Know Your Customer Match** - Match customer information
- **Know Your Customer Tenure** - Get customer tenure information
- **Number Recycling** - Check if a number has been recycled
- **Number Verification** - Verify a mobile number against the device ✅
- **One Time Password SMS** - Send OTP via SMS
- **Scam Signal** - Detect and signal scam attempts
- **SIM Swap** - Detect SIM swap events ✅
- **SIM Swap Subscriptions** - Subscribe to SIM swap notifications

### Location Services
- **Geofencing Subscriptions** - Subscribe to geofencing events
- **Location Retrieval** - Retrieve device location ✅
- **Location Verification** - Verify device location
- **Population Density Data** - Get population density information
- **Region Device Count** - Get device count in a region

### Communication Services
- **WebRTC Call Handling** - Handle WebRTC calls
- **WebRTC Event Subscription** - Subscribe to WebRTC events
- **WebRTC Registration** - Register for WebRTC services

### Communication Quality
- **Application Profiles** - Manage application profiles
- **Connectivity Insights** - Get connectivity insights
- **Connectivity Insights Subscriptions** - Subscribe to connectivity insights
- **QoS Profiles** - Manage Quality of Service profiles
- **QoS Provisioning** - Provision Quality of Service
- **Quality on Demand** - Request quality on demand

### Device Information
- **Connected Network Type** - Get connected network type
- **Connected Network Type Subscriptions** - Subscribe to network type changes
- **Device Identifier** - Get device identifier
- **Device Reachability Status** - Get device reachability status
- **Device Reachability Status Subscriptions** - Subscribe to reachability changes
- **Device Roaming Status** - Get device roaming status
- **Device Roaming Status Subscriptions** - Subscribe to roaming status changes

### Computing Services
- **Simple Edge Discovery** - Discover edge computing resources

### Payments and Charging
- **Blockchain Public Address** - Manage blockchain public addresses
- **Carrier Billing** - Handle carrier billing
- **Carrier Billing Refund** - Process carrier billing refunds
